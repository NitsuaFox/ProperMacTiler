# Proper Mac Tiler is now VibeDesktop

**[Download VibeDesktop](https://github.com/NitsuaFox/VibeDesktop-Releases/releases/latest)**

VibeDesktop is a native macOS window layout app with customizable layouts, full-section drag snapping and signed updates.

This repository preserves the update address used by existing Proper Mac Tiler installations. Use **Check for Updates** in the app to move to VibeDesktop while keeping your saved layouts and preferences.

Only downloads and this notice are public here. Application source is private. New releases and the current update feed live in [VibeDesktop-Releases](https://github.com/NitsuaFox/VibeDesktop-Releases).
